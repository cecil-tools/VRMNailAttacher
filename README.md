# VRMNailAttacher

> ** VRM アバターにネイルチップ（3Dモデル）を自動装着し、テクスチャ差し替え・カスタマイズができる Web ツール**

---

## 📖 概要

**VRMNailAttacher** は、人型 3D アバター（VRM 0.x / 1.0）に対して、ネイルチップ（爪の 3D モデル）を自動で各指の先端ボーンへ追従・アタッチし、ブラウザ上で直感的にテクスチャの差し替えや質感調整を行い、新たな VRM モデルとしてエクスポートできる Web アプリケーションです。

従来、アバターにネイルチップを装着するには Blender や Unity 等の 3D DCC ツールでのボーン設定やウェイト調整が必要でしたが、本ツールを利用することで、ブラウザのみで簡単にネイル付きアバターを作成できます。

---

## ✨ 主な機能

- **VRM 読み込み・プレビュー**
  - VRM 0.x / 1.0 ファイルのドラッグ＆ドロップ読み込み
  - Three.js によるリアルタイム 3D ビューアー表示（カメラ回転・ズーム・パン）
- **ネイルチップ 3D モデルの自動装着 (Auto-Attach)**
  - 各指（親指〜小指の末節骨ボーン / Distal Phalanges）の検出と位置・回転の自動フィッティング
  - 手の大きさや指の形状に応じたオフセット、スケール、角度の微調整機能
- **テクスチャ差し替え & カスタマイズ**
  - ネイルチップ用テクスチャ画像（PNG / JPG）のアップロード・即時反映
  - 指個別（1本ずつ）または両手一括でのデザイン・カラー適用
  - マテリアル質感の調整（光沢、マット感、透明度など）
- **VRM エクスポート**
  - ネイルチップモデルとテクスチャが結合・再セットアップされた VRM ファイルの出力・ダウンロード
  - 既存アバターのボーン構造・モーフ・マテリアル設定を保持

## 🚀 開発環境のセットアップ

> [!IMPORTANT]
> アプリケーションのコードおよび設定ファイルはすべて `app/` 配下に存在します。  
> `npm` コマンドを実行する際は、**必ずカレントディレクトリを `app/` に移動して実行してください。**

### 1. リポジトリのクローン & 移動

```bash
git clone <repository-url>
cd VRMNailAttacher/app
```

### 2. パッケージのインストール

```bash
npm install
```

### 3. 開発サーバーの起動

```bash
npm run serve
```

ローカルサーバーが起動し、ブラウザから `http://localhost:8080` でアクセスできます。

### 4. 主なコマンド一覧

すべてのコマンドは `app/` ディレクトリ内で実行します。

| コマンド | 説明 |
| :--- | :--- |
| `npm run serve` | 開発用ローカルサーバーの起動 (`http://localhost:8080`) |
| `npm run build` | 本番用ビルド（`dist/` ディレクトリに成果物を出力） |
| `npm run lint` | ESLint によるコード静的解析・検証 |
| `npm run deploy`| ビルドおよび Firebase Hosting へのデプロイ |

## 💡 基本的な使い方・ワークフロー

1. **VRM モデルの読み込み**
   - 画面のドロップエリアに VRM ファイルをドラッグ＆ドロップします。
2. **ネイルチップの自動装着**
   - ネイルアタッチを実行すると、各指のボーンを検出し、ネイルチップ 3D モデルが適切な位置・角度・サイズで自動配置されます。
   - 必要に応じて、指先ごとのオフセットスライダーで位置を微調整します。
3. **テクスチャの差し替え・カスタマイズ**
   - プリセットから選択するか、お好みのネイルデザイン画像（PNG / JPG）をアップロードして全指に適用できます。
   - ネイルマテリアルは1つに集約・最適化されており、ドローコールの削減やVRChat等のパフォーマンスランク低下を防ぎます。
4. **VRM のエクスポート**
   - 画面上部の「VRM エクスポート」ボタンをクリックし、ネイルが装着された VRM ファイルをダウンロードします。
